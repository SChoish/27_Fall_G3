# 제조 전 개발 검증과 설계 동결

아래 에너지는 개발용 긴 패킷에서 선택한 회로의 값이다. 네 채널 모두에서 최적 공통 위상을 허용한다. 블라인드 시험에서는 짧은 세 관측만으로 위상을 고른다.

각 셀은 짧은 72회, 긴 24회, 총 96회를 배정했다. 설계·패킷이 같으면 캐시를 공유했다. 중단 시 체크포인트에 남지 않은 중복 계산은 포함할 수 없다. 모든 반환 설계가 개발 기준을 통과했다. 일부 MLP 피팅에서 L-BFGS 수렴 경고가 있었으며 세 seed 모두 설계 반환 및 물리 검증까지 완료했다.

locks 아래의 실제 동결 파일로 제조 탐색을 반복하지 않고도 confirm_phase_sizing의 입력 디렉터리를 지정할 수 있다. 49103은 phase_size_s{21,22,23}, 49105는 phase_reserve_s{21,22,23}에 대응한다.

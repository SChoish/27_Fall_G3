# 관측 두 번으로 보정한 독립 채널 결과

bo13 고정 회로, 새 채널 seed 49106, 채널별 256비트 검증 패킷 네 개. 개발에서 선택한 고정 경로는 32→48이다. 적응 경로는 첫 64비트 응답을 보고 16/48 중에서 고른다. 한 번만 읽는 대조군도 같은 개발 참조 자료를 쓴다.

|방법|보정 비트/배선|RC|RLC|전체 통과|보정 TX pJ/링크|
|---|---:|---:|---:|---:|---:|
|fixed32|0|2/6|2/6|4/12|0.00|
|one|64|1/6|3/6|4/12|41.33|
|two_fixed|128|2/6|3/6|5/12|79.34|
|two_adaptive|128|2/6|3/6|5/12|79.34|

적응 경로는 코드 16을 5회, 48을 7회 사용했다. 고정 경로 대비 추가 통과 0개, 새 실패 0개였다. 실제 검증 payload 송신 에너지는 공통 0.201715 pJ/bit다. 총 72개 transient를 공유했다. 표의 보정 비용은 세 배선 payload 전류 적분값으로, 수신기 전력과 프리앰블은 제외했다.

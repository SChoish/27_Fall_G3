# 판정 경계의 시간 해상도 검증

49102 독립 시험에서 RC/RLC별로 grid 통과와 실패 각각 마진 0.08에 가장 가까운 조합 하나를 골랐다. 기존 보정 코드·회로·채널·패킷은 고정하고 ngspice 최대 시간 간격만 UI/64에서 UI/128로 줄였다. 재보정 없이 검증용 네 패킷을 다시 적분했다.

|채널|설계|고정 코드|원래 마진|세밀 마진|원래 통과 패킷|세밀 통과 패킷|TX pJ/bit 변화|
|---|---|---:|---:|---:|---:|---:|---:|
|RC 18|bo11|32|0.096644|0.096607|4/4|4/4|-0.000009|
|RC 0|bo13|32|0.062681|0.062792|1/4|1/4|-0.000007|
|RLC 9|bo13|32|0.080853|0.080915|4/4|4/4|-0.000006|
|RLC 9|bo12|32|0.079613|0.079673|2/4|2/4|-0.000006|

16개 transient를 추가했다. 네 조합 중 0개에서 전체 통과 판정이 바뀌었다. 경계 표본을 의도적으로 골랐으므로 이 비율로 전체 수치를 보정할 수 없다.

# 원격 체크아웃의 물리 재현 검증

저장된 주 시험에서 seed 22 BO와 국소 MLP의 grid 통과 여부가 처음 달라진 곳은 채널 번호 2이다. 채널 seed(49103) 및 설계 벡터로 보정용 64비트 세 패킷과 검증용 512비트 네 패킷을 처음부터 재생성했다. 체크포인트나 기존 파형을 사용하지 않았다.

|회로|위상|통과 패킷|오류 수|최악 마진|TX pJ/bit|
|---|---:|---:|---:|---:|---:|
|BO|32|3/4|0|0.05007085|0.21671702|
|국소 MLP|32|4/4|0|0.10644565|0.22771774|

두 설계의 위상·오류 수·통과 여부가 원본과 일치했고, 마진·overshoot·에너지는 절대오차 10⁻⁹ 이내였다. 이 검산에 14회가 들었다. 같은 시험의 재측정이므로 통과율의 표본 수는 늘지 않는다.

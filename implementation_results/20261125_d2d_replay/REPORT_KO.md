# D2D 신경망 탐색 실험

같은 NGSPICE 39 회로에서 측정한 TX 공급 에너지다. 독립 단위는 optimizer seed이며, 각 평가 패널은 모든 방법이 공유한다.

## 과거 데이터 없이 시작 (seed 3–5)

공통 초기 8개를 포함하여 짧은 18회와 긴 최대 3회로 선택한 뒤 기존/전이 RC 채널에서 새 random 패킷 16개를 평가했다.

|방법|전체 통과 seed|통과 설계 평균 TX pJ/bit|기준과 공통 통과한 seed / 평균 에너지 차이|
|---|---:|---:|---:|
|bo|3/3|0.186339|3 / +0.000000|
|replay|3/3|0.220148|3 / +0.033809|
|replay_feedback|3/3|0.217157|3 / +0.030818|
|random|3/3|0.212967|3 / +0.026628|
|ga|3/3|0.195814|3 / +0.009475|

|seed|BO|MLP|MLP+피드백|Random|GA|
|---|---|---|---|---|---|
|3|통과 0.16731|통과 0.22015|통과 0.22015|통과 0.21223|통과 0.20475|
|4|통과 0.22015|통과 0.22015|통과 0.22015|통과 0.20653|통과 0.21187|
|5|통과 0.17155|통과 0.22015|통과 0.21117|통과 0.22015|통과 0.17082|

MLP 두 방법은 같은 일정이다. 긴 개발 평가에서 얻은 lane별 마진·overshoot 악화를 주변 후보에 적용한 효과를 비교한다. BO와 GA/Random은 마지막 검증 일정이어서 이들과 비교한 차이는 전체 탐색 절차의 차이다. GA는 steady-state binary tournament, blend crossover, 정규화 좌표에서의 Gaussian mutation을 쓴다.

## 과거 개발 데이터 공유 (seed 6–10)

기존 개발 설계 115개(고유 설계 기준 460 case 평가 상당)를 공유하고, BO와 MLP는 각각 96회 이하의 추가 평가를 받았다. archive_only는 기존 후보를 최대 24회 검증했다. 동일 후보의 반복 측정은 캐시로 공유하되 방법별 논리 예산은 따로 계산한다. 이 MLP는 archive 및 온라인 측정을 함께 적합하며 긴 개발 평가는 최종 선택에만 쓴다. 후보 선택을 동결한 뒤 기존 채널 2개와 새 RC 채널 2개에서 채널마다 8개씩, 총 32개의 128-bit 패킷을 평가했다.

|방법|전체 통과 seed|통과 설계 평균 TX pJ/bit|기준과 공통 통과한 seed / 평균 에너지 차이|
|---|---:|---:|---:|
|archive_only|0/5|–|0 / –|
|archive_bo|0/5|–|0 / –|
|archive_mlp|0/5|–|0 / –|

|seed|archive_only|archive_bo|archive_mlp|

|8|실패 0.15342|실패 0.15342|실패 0.15342|
|9|실패 0.15342|실패 0.15342|실패 0.15342|

archive_only는 같은 후보를 매번 반환하므로 5개의 독립 설계를 평가했다고 해석할 수 없다. 두 실험은 seed, 패킷 및 채널이 달라 절대 에너지를 직접 비교하지 않는다. 기존 PPO의 행동/상태는 링크 운용 설정을 대상으로 하므로 이번 6차원 sizing 실험에서는 신경망 회귀와 측정 버퍼를 사용했다. PPO/SAC 및 기존 ALARM의 새 프로토콜 성능은 여기서 측정하지 않았다.

신경망 최적화에서 scikit-learn L-BFGS 수렴 경고가 기록됐다 (430회). 반환된 파라미터를 사용하고 최종 품질과 에너지는 ngspice로 평가했다. 학습기 수렴과 예측 품질을 개선할 여지가 있다. 환경은 scikit-learn 1.8.0, NumPy 2.3.5, SciPy 1.17.0이다.

공통 반환 설계는 32개 중 27개를 통과했다. 실패 5개는 모두 같은 기존 채널에서 나온 새 패킷이었다. 중심 판정 비트 오류는 0개였지만 수신 전압의 최저 마진이 0.05839 V/VDD로 기준 0.08에 미달했다. 새 채널 16개 패킷은 모두 통과했다. BO와 MLP가 각각 제안한 신규 설계 50개 중 짧은 개발 평가를 통과한 수는 각각 0개와 16개였다. 장기 검증 후 반환한 설계는 모두 같았다.

# 실제 실행 결과와 범위

SKY130 TT 트랜지스터 모델을 ngspice 39에서 실행했습니다. 다음 수치는 모두 제공한
파형에서 계산한 값이며, 칩 측정 결과는 아닙니다.

## 기본 기능 확인

입력은 0.8, 1.1, 0.85, 1.05, 0.8, 0.9V 순서, 샘플링 용량은 15pF,
샘플링 속도는 1MS/s, acquisition time은 200ns입니다. 오차 한도는 1mV입니다.

| 설계 | 최대 hold 오차 | 에너지 / sample | 조건 만족 |
|---|---:|---:|---|
| 원래 nominal OPAMP + R=200Ω, C=10pF | 2.7283mV | 158.4997pJ | 실패 |
| 이전 OPAMP sizing + R=200Ω, C=10pF | 3.3702mV | 169.5489pJ | 실패 |
| ADC reference: 이전 sizing + R=500Ω, C=1pF | **0.9813mV** | **169.2982pJ** | 성공 |
| ADC reference, 시간 간격을 4배 촘촘하게 재평가 | **0.9829mV** | **169.2983pJ** | 성공 |

ADC reference는 테스트벤치를 개발하면서 RC 값을 확인해 얻은 설계입니다. 학습 방법이
찾았다고 표시하지 않습니다. source 데이터와 모든 최적화 방법의 초기 후보에 넣었으며,
그 평가도 각각 새 SPICE query로 비용에 포함했습니다.

기본 최대 time step 2ns와 dense 0.5ns의 최대 오차 차이는 **0.001601mV**였습니다.
모델이 포함된 독립 `examples/adc_reference.cir`를 별도 출력 폴더에서 직접 ngspice로
실행했으며, Python으로 생성한 같은 조건의 오차·에너지와 일치했습니다.

1MS/s이므로 169.298pJ/sample은 약 **169.298µW**의 평균 공급 전력입니다.
이 값은 앰프와 클록 인버터의 전원 에너지를 포함하며, 이상적인 자극원의 에너지는
별도로 기록합니다. 초기화·dummy cycle 에너지는 평가에서 제외합니다.

## 최적화·학습 경로 실행 확인

새 ADC 조건에서 source 설계 24개를 실제로 평가했습니다. 모두 측정 유효했고,
학습/검증/테스트는 16/4/4개입니다. 회귀와 RNC 모델을 각각 150 epoch 이내에서
학습하고 검증 오차로 checkpoint를 선택했습니다. 테스트 데이터는 선택에 쓰지 않았습니다.

각 방법은 seed 0, 총 16회 평가로 실행했습니다.

| 방법 | 첫 성공 query | 최종 feasible 에너지 | 초기 ADC reference보다 개선 |
|---|---:|---:|---|
| 무작위 탐색 | 3 | 169.2982pJ | 없음 |
| GA | 3 | 169.2982pJ | 없음 |
| 회귀 + 지역 탐색 | 3 | 169.2982pJ | 없음 |
| 회귀 + RNC + 지역 탐색 | 3 | 169.2982pJ | 없음 |

**네 방법 모두 알려진 초기 reference를 유지했습니다. 이번 결과는 알고리즘 우위의
증거가 아니라, 데이터→학습→후보 생성→새 회로 평가 경로의 작동 확인입니다.**
소스 학습 데이터의 최선 설계를 조회하는 방식도 같은 169.2982pJ 설계를 반환합니다.
RNC를 포함한 방법의 필요성과 개선 정도를 판단하려면 더 충분한 source 데이터·탐색
예산·여러 seed·여러 요구 조건에서 이 lookup 기준선과 비교해야 합니다.

회귀와 RNC의 유효 테스트 4개에 대한 정규화 MSE는 각각 0.22456과 0.22385입니다.
표본이 작으므로 이 차이로 표현학습 효과를 해석하지 않습니다. 원본 체크포인트,
데이터 분할, 각 학습의 검증 이력은 함께 제공합니다.

## 다른 조건에서는 어떻게 되는가

동일한 ADC reference를 바꾸지 않고 다음 조건에서 평가했습니다. 각 행은 nominal에서
해당 조건 하나만 바꾼 경우입니다.

| 조건 | 최대 hold 오차 | 1mV 조건 |
|---|---:|---|
| nominal: 15pF, 200ns, 27°C | 0.9813mV | 성공 |
| 샘플링 용량 30pF | 18.6449mV | 실패 |
| acquisition 100ns | 19.0914mV | 실패 |
| 온도 85°C | 2.2269mV | 실패 |

따라서 제공한 reference는 **nominal 조건에서만 확인한 설계**입니다. 여러 조건에서의
설계 최적화를 실행할 수 있도록 `configs/stress.json`과 복수 조건 평가 API를 넣었습니다.
이 네 조건을 모두 만족하는 설계를 찾았다고 주장하지 않습니다.

## 검증 내역

- 여섯 측정 검사가 통과했습니다: 참 sample-and-hold, 다음 입력과 hold 목표의 구분,
  정적 오프셋 보존, 전력/에너지 단위, 적분 경계, 클록 off 오류 검출.
- RNC의 loss와 gradient를 거리 tie를 포함한 직접 계산식과 비교해 확인했습니다.
- 네 방법의 64회 검색 비용과 성공 판정을 원본 기록에서 재계산했습니다.
- 공통 초기 8개에 대해 방법 간 24쌍의 후보와 실제 회로 측정치가 정확히 같습니다.
- 데이터 24회와 탐색 64회는 별도로 기록합니다. 개발 단계 및 dense·standalone·stress
  검증 실행은 이 숫자에 포함하지 않았으며, 그 기록은 `results/development/`와
  `results/validation/`에 있습니다.

전체 재검산은 `python validate_bundle.py`, 측정 검사들은
`python -m unittest discover -s tests -v`로 실행할 수 있습니다.

공정 변화·mismatch·잡음·전체 ADC의 선형성·ENOB·레이아웃 추출은 검증하지 않았습니다.
현재 범위는 실제 MOS 샘플링 부하를 구동하는 회로도 단계의 고정 topology sizing입니다.

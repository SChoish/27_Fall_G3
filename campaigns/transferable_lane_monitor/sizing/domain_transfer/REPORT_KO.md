# 다른 PDK와 lane 부하에서 어떤 지식이 옮겨가는가

SKY130의 2단·4단 버퍼와 두 출력 부하로 학습한 뒤 네트워크의 소스 가중치를 고정했다. 대상 회로의 제약을 만족하면서 EDP를 5%, 10% 줄이는 첫 설계를 찾기까지 필요한 과도해석 수를 비교했다. 단수와 관계없이 설계 변수는 첫 단·마지막 단의 폭 배율 두 개이며 중간 단의 배율은 기하 보간했다. 동일한 25개 후보가 있어 설계 순위만 재사용하는 방법도 강한 기준선이다.

## 전이 축

| 대상 | 변경 내용 |
|---|---|
| lane | SKY130 4단, 부하 8/12 → 16/24 fF |
| pdk | 4단·부하 유지, SKY130 1.8 V/0.15 µm → GF180MCU 3.3 V/0.28 µm |
| both | GF180 4단 + 두 배 부하 |
| topology | GF180 + 두 배 부하 + 소스에 없는 6단 체인 |
| wire | 추가 검사. SKY130 4단에서 기준 부하를 양단에 절반씩 분배하고 120 Ω 배선으로 연결. 수신단에서 측정 |

GF180에는 공식 typical 3.3 V 4단자 MOS 모델의 원래 BSIM 계수를 사용했다. 전압 강하 비율은 동일하게 두었고 공정의 명목 전압과 채널 길이는 함께 바뀐다. 모든 회로가 TT이며 실측 실리콘, 배선 추출 기생성분, 다중 lane 상호결합은 후속 대상이다. 전이 가능성의 독립 단위는 대상 회로다. 모델 초기화 시드 여섯 개를 서로 다른 회로 여섯 개로 세지 않는다.

## 무엇을 전달했는가

- 원천 순위 재사용은 네 소스 도메인의 동일 후보별 전기량 예측 목표를 평균한 뒤, 새 회로에서 그 순서대로 시도한다.
- MLP는 단계별 폭과 배율·신호 경로상 위치·입출력 여부·부하·단수로 단계별 임베딩을 학습한다. 단계별 임베딩의 평균과 출력단 임베딩을 연결해 다섯 전기적 지표를 동시에 예측한다.
- 그래프 모델은 같은 입력에 인접 단계와 자기 자신을 포함한 단일 attention 층을 추가했다. 이 단순화 버전은 이웃의 임베딩으로 attention 가중치를 계산하고 자기 표현에는 잔차 연결을 쓴다. 물리적인 signal-flow chain을 사용한다. node와 adjacency를 일관되게 재배열했을 때 그래프 표현의 동일성을 확인했다.
- frozen은 encoder와 head를 모두 고정한다. new head는 encoder만 옮기고 기준 설계 비율에서 시작해 새 head를 피팅한다. head adapt는 소스 encoder와 head를 모두 가져와 목표 회로 개발 측정으로 선형 head의 잔차를 피팅한다. 모든 모델의 학습 표적은 EDP와 네 가지 전기 제약의 로그 비율이다. 확인 코너 데이터는 모델에 전달하지 않는다.
- random head 실험은 학습하지 않은 랜덤 MLP encoder와 새로 피팅하는 head를 사용한다. no edges 실험은 소스에서 학습한 attention 모델의 추론 시 자기 연결만 남긴다. 각 방법의 탐색은 고정된 25개 후보로 제한했다. cold BO에는 해당 후보에 대한 목표확률 획득함수를 적용했다.

## 비교 결과

표의 숫자는 40회까지의 제한평균이다. 같은 예산에서 목표에 도달할 수 있는 칸은 아래 모두 6/6 성공했다. 기준 회로 4회와 첫 후보 개발·확인 4회가 필요하므로 최초 성공의 하한은 8회다. 소스 시뮬레이션 비용은 이 표에서 분리했다.

| 대상과 목표 | 독립 BO | 원천 순위 | MLP 새 head | MLP head 보정 | 그래프 새 head | 그래프 head 보정 |
|---|---:|---:|---:|---:|---:|---:|
| SKY130 4단 + 120 Ω π 배선, 5% | 10.0 | 8.0 | 13.3 | 8.0 | 13.3 | 8.0 |
| GF180 4단, 10% | 12.0 | 8.0 | 13.0 | 8.0 | 12.7 | 8.0 |
| GF180 4단 + 두 배 부하, 5% | 10.0 | 8.0 | 13.0 | 9.7 | 15.0 | 10.0 |
| GF180 6단 + 두 배 부하, 10% | 10.0 | 16.0 | 18.7 | 11.7 | 20.0 | 12.7 |

GF180 4단에서 10%를 만족한 후보는 25개 중 6개였다. 원천 순위가 고른 첫 설계가 이미 통과했으므로 GAT 고유의 이점으로 해석하기 어렵다. GF180 6단·두 배 부하에서는 10% 통과 후보가 하나였다. 첫 설계부터 10%에 성공한 것은 head 보정 MLP가 2/6, 같은 방식의 그래프가 0/6이었다. 두 방법은 첫 관측 전에는 각자의 고정 모델과 같은 설계를 고른다. 첫 후보의 5% 성공률은 MLP 2/6, 그래프 4/6으로 순서가 달랐다. 이 조건에서 그래프 전체 고정의 10% 도달 비용은 29.7회, 새 head는 20.0회, 소스 head 보정은 12.7회였다. 모델 고정과 적응 간 차이, 달성하려는 목표의 난이도를 함께 봐야 한다.

SKY130의 두 배 부하에서 전기 제약을 지킨 후보의 최대 EDP 개선은 2.96%였다. 해당 격자에서 5% 도달 속도로 방법을 구분할 수 없다. 이 사실은 연속 설계공간에서의 불가능성을 뜻하지 않는다.

원천 4개·대상 5개의 측정표는 총 936회의 새 ngspice 과도해석으로 만들었다. 소스 도메인당 104회 중 모델이 실제 사용한 것은 개발 코너 52회로, 공통 원천 학습 정보 비용은 208회다. 소스 확인 코너까지 포함한 실제 표 생성 비용은 416회였다. 300개 탐색 기록은 이 측정표를 재사용한 결과다. 다섯 대상에서 대표 제안 순서를 다시 SPICE로 실행한 142회에서도 도달 횟수가 일치했다. 936회와 142회는 최종 데이터에 대한 비용이며 초기 동작 확인 및 폐기한 실행은 제외했다. 배선 검증 중 후보 폭 변경이 반영되지 않은 초기 넷리스트를 발견해 생성 순서를 수정했으며, 최종 120 Ω 배선 표와 재검증 기록은 전부 다시 계산했다. 후보에 따라 소비 에너지가 실제로 바뀌는지도 자동 검사한다.

## 연구 방향

전이 모델의 우선 후보는 전기량별 응답을 소스에서 학습한 뒤 소스 head를 유지하고, 대상 실측으로 잔차를 보정하는 구조다. 배선과 소자 수가 다른 회로에 적용하려면 소자·net·lane별 타입 및 핀 연결, R·C·결합을 포함하는 그래프 입력, 각 조절 가능 소자에 공유되는 상대 폭 변경 head를 사용해야 한다. PDK별 VDD·최소 길이·합법 폭 범위로 동작 범위를 정규화하고, 소자 특성 측정에 SPICE를 쓰면 해당 비용도 포함한다. PDK별로 바뀌는 출력 민감도는 소수 측정으로 조정할 수 있다. 단순 순위 재사용, 집합형 MLP, 동일 입력의 attention과 균등 메시지 집계를 같은 출발 데이터로 비교해야 그래프의 기여를 평가할 수 있다. 기존 연구도 다양한 기술 노드·회로에서 GCN을 사용한 전이를 다루므로 그래프 사용 자체는 연구 기여가 아니다. [GCN-RL Circuit Designer, DAC 2020](https://hanlab.mit.edu/projects/gcn-rl-circuit-designer)

## 재현

원천 SKY130 모델은 기존 sizing 폴더와 같은 파일이다. GF180 원본 Git blob은 561e63453512eb8c614d7d45ac1c6cc2c41e0111이고, prepare_gf.py로 모델 정보를 추출한다. [GF180 소자 모델](https://github.com/google/globalfoundries-pdk-libs-gf180mcu_fd_pr/blob/main/models/ngspice/sm141064.ngspice)

이 디렉터리에서 prepare_gf.py에 원본과 출력 모델 경로를 전달하고, data.py에 --sky, --gf, --wasm, --node, --out measured를 전달한다. evaluate.py measured가 레이블이 가려진 후보 조회 방식으로 궤적과 요약을 생성한다. verify.py는 시드 11의 그래프 head 보정이 택한 후보 순서를 실제 SPICE로 다시 측정한다. audit.py는 각 궤적의 설계 순서·원시 측정에서 최초 통과와 누적 비용을 재계산한다. 결과 ZIP에는 측정표·시드별 궤적·재검증 기록이 있다.

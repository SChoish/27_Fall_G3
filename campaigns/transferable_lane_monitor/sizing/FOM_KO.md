# G3 버퍼 설계의 FoM과 알고리즘 평가

**회로가 도달해야 하는 목표**는 지연, 출력 전이, 논리 레벨, 전원 강하 민감도를 만족하면서 기준 버퍼보다 최악 조건 에너지·지연곱(EDP)을 10% 줄이는 것이다. **탐색 성능**은 이 목표가 확인될 때까지 실제 사용한 SPICE 과도해석 수로 측정한다. 20-lane 패키지에서 최악 lane의 마진이 보전되는지 별도로 시험한다.

## 셀 단위 정의

설계 폭을 x, 동일한 단수의 기준 폭을 x₀, 부하·온도·전원압 조합을 c라 둔다. 동일한 부하를 두 설계의 출력에 연결한다.

- E(x,c)는 주기 정상상태에 가까운 두 번째 상승·하강을 포함하는 2 ns 동안 −VDD × I(VDD)를 적분한 공급 에너지다. 출력 부하 충전, 셀 내부 충방전, 단락전류, 해당 구간 누설을 포함한다. 이상적인 입력 펄스원의 구동 에너지는 제외한다. 입력단 폭이 기준값을 넘지 못하게 제한한다.
- D(x,c)는 입력과 출력의 50% 전압 교차로 얻은 상승·하강 전달지연 중 큰 값이다.
- F(x) = max_c { E(x,c) D(x,c) / [E(x₀,c) D(x₀,c)] }. 낮을수록 좋다. 코너마다 동일 조건의 기준 셀과 먼저 비교하므로 부하나 전원이 다른 두 측정의 극값을 곱하지 않는다.
- 기본 목표는 F ≤ 0.90이고, 0.95와 0.80도 함께 보고한다. 설계 목표와 숫자 허용치는 이 벤치마크에서 선택했다. 표준에서 가져온 합격선은 없다.

| 필수 제약 | 같은 기준 회로 대비 조건 |
|---|---|
| 상승·하강 전달지연 | 각 동작점에서 두 에지 각각 ≤ 1.10배 |
| 출력 상승·하강 시간 | 20–80%와 80–20% 각각 ≤ 1.10배 |
| 논리 스윙 | 반주기 후반 두 고정 시점의 HIGH ≥ 0.9 VDD, LOW ≤ 0.1 VDD |
| 공급 강하에 의한 위상 이동 | 같은 온도·부하에서 전압을 낮췄을 때 생기는 에지별 지연차 절댓값의 최댓값 ≤ 기준값의 1.05배 |

최소 EDP 버퍼 사이징은 에너지와 전파지연을 함께 다룬 기존 CMOS 연구와 연결된다. G3에서는 열화된 동작을 에너지 절감으로 상쇄하지 못하도록 타이밍 제약을 별도로 둔다. 전원 변화에 의한 지연 민감도는 PSIJ 연구의 측정 대상이다. 이 파일럿은 정적 공급전압 두 점의 차이를 측정한다. 실제 전원망 잡음 스펙트럼이나 RMS jitter는 별도 파형 검증이 필요하다. [Kang et al., GLSVLSI 2003](https://mpedram.com/Papers/buffersizing-glsvlsi03.pdf) · [Sun et al., IEEE TVLSI 2021](https://doi.org/10.1109/TVLSI.2021.3072799)

## 검증 순서와 비용

1. 각 회로의 기준 폭을 네 조건에서 실제 평가한다. 탐색용은 8 fF·27°C에서 1.80/1.66 V, 확인용은 12 fF·70°C에서 1.80/1.62 V다. 네 조건 모두 SKY130 TT이고 공정 코너 확률이나 수율을 추정하지 않는다.
2. 새 설계를 탐색 조건 두 점에서 평가한다. 제약과 5% 목표를 통과할 때마다 나머지 두 확인 조건을 수행한다. 확인측정 결과는 제안기에 전달하지 않는다. 두 부하에서 최종 제약과 해당 EDP 목표를 전부 만족한 최초 시점이 도달 시점이다. 모든 알고리즘에 동일한 검증 트리거를 사용한다.
3. 1회는 한 netlist·한 동작점의 transient다. 같은 파형에서 에너지, 지연, slew를 함께 읽으면 1회다. 성공·실패 시도와 확인 호출도 모두 포함한다. 시간 제한까지의 미도달을 유지하고 40회 이내 성공률과 제한평균 min(T,40)을 함께 보고한다. 이 평균에서 미도달은 40의 비용을 차지한다. 40회가 통과를 뜻하지는 않는다.
4. 전이 방법은 새 회로의 추가 호출 수와 출발 회로의 데이터 생성 비용을 함께 공개한다. 같은 source 데이터를 여러 회로가 재사용하는 경우에만 실제 대상 수를 명시해 상각한다. COCO의 고정 목표 도달 횟수 평가와 AutoCkt의 학습·배치 비용 구분이 이 설계의 근거다. [Hansen et al., COCO Performance Assessment](https://arxiv.org/abs/1605.03560) · [Settaluri et al., DATE 2020](https://www.date-conference.com/proceedings-archive/2020/pdf/0505.pdf)

## 패키지 수준의 별도 판정

선택한 버퍼 폭을 고정하고 5개 부하 × 6개 전원에서 얻은 새 SPICE 지연표를 같은 수신기·같은 패킷·같은 드리프트에 대입한다. 각 블록에서 20개 lane 중 하나라도 마진 0.25 미만이면 실패다. 네 조건 각각에서 새 설계와 기준 설계의 미달률 차이(새 설계 − 기준)의 단측 상한이 +1%p 이하면 통과다. 궤적을 대응시켜 10,000회 재표집하고 네 조건에 Bonferroni 보정을 적용한다. 1%p는 파일럿의 모델 수준 비열등성 허용치다. 제품에 절대 미달률 요구사항이 있으면 이를 별도 필수 제약으로 추가해야 한다.

패키지 시험의 32회 lane 관측은 SPICE eval로 세지 않는다. 30점 지연표의 각 transient는 센다. 이 링크 모델은 TT 지연과 패키지 주파수 응답을 결합하며 검증 결과는 합성 전원 강하 모델과 고정 패킷 뱅크에 조건부다. UCIe의 pJ/bit에는 PHY와 어댑터 등 훨씬 넓은 범위가 포함된다. 이 실험의 단위는 버퍼 1주기의 fJ와 ps이며 BER 또는 UCIe 적합 판정으로 환산하지 않는다. [UCIe 1.1, Table 6](https://tmng-al.uspto.gov/resting2/api/casedoc/cms/case/99231699/tmdocument/20250612064611159321SPE0011.pdf)

## 셀 검증과 패키지 검증을 함께 읽는 법

셀의 최초 도달 시점에는 네 동작점 확인 비용이 포함된다. 전체 30점 지연표로 수행하는 패키지 검증은 대표 설계에만 적용했다. 전체 알고리즘의 패키지 합격까지 속도를 비교하려면 모든 방법에 같은 패키지 확인 트리거를 적용하고, 이전에 시뮬레이션한 동일 동작점은 캐시로 재사용하며 추가로 실행한 SPICE 수를 도달 시점에 포함해야 한다. 현재 속도표의 종점은 셀 FoM이다.

SPICE 시간 간격에 민감한 경계 사례를 확인하기 위해 셀과 패키지를 모두 통과한 2단 5% 및 4단 10% 대표 후보를 0.25 ps 간격으로 다시 평가했다. 1 ps 실험과 분리해 기준 회로와 후보 네 조건을 각각 실행했으며, 두 회로에 추가 16회가 들었다.

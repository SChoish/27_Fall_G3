# 익명 폭 탐색에서 소스 예측 적응

1차 목표는 정밀 검증까지 포함한 5% EDP 개선 최초 도달의 100회 제한 평균, 2차는 10%와 각각의 성공률이다. 새 회로 결과를 확인하기 전 아래 조건과 판정 기준을 고정한다. 지연·slew·레일·공급 민감도 제약, 개별 SPICE transient 과금, 같은 네 무작위 후보, 학습 시 확인 코너 차단을 유지한다. 후보에는 익명 로그 폭, nominal, 허용 범위와 타깃 개발 측정만 제공한다. 기존 SKY130 소스 200회를 공유한다.

기준은 타깃 전용 BO, 고정 MLP + BO, 고정 GAT + BO다. 신규 방법 두 가지 모두 GP kernel·후보 512개·불확실성·모델 가중치를 고정한다. 첫째는 MLP의 예측 진폭을 지표별로 0~1배까지 줄인다. 둘째는 MLP와 GAT 예측 사이의 지표별 볼록 결합을 사용한다. 타깃 개발 관측에서 nominal 대비 오차를 GP 공분산 역행렬로 가중하고, 적응 계수의 제곱에 2배 벌점을 준다. 오차는 지표별 관측 표준편차(하한 0.02)로 정규화한다. 초기 기준은 두 방법 모두 MLP다. 계수 추정으로 추가 SPICE를 호출하지 않는다.

기존 6단·2단 회로 쌍과 seed 71–73은 개발 비교다. 별도 전이 평가는 같은 토폴로지에서 부하 (0.82,1.55)·결합 3.35 fF로 변경한 쌍과 새 5인버터 분기 구조 쌍이다. 후자의 부모는 (-1,0,0,-2,3), nominal (1,1.65,2.65,1.1,2.05), 출력 (1,2,4), 부하 (0.85,1.15,1.40), 결합 2.3 fF다. 두 경우 모두 SKY130/GF180과 seed 81–83을 사용한다. 순수 부하 변경의 인과 효과에는 공통 seed 재평가가 더 필요하다.

기존 MLP + BO 교체 조건은 미사용 4조건 전체에서 5% 제한 평균이 낮고 성공 수가 줄지 않으며, 부하 이동 및 분기 토폴로지 각각에서도 5% 성공 수가 줄지 않는 것이다. 두 후보가 통과하면 미사용 5% 제한 평균이 낮은 것을 이 소규모 비교의 후속 후보로 채택한다. 선정에 사용한 회로에서의 순위는 향후 독립 재현이 필요하다. 고정 GAT와 10% 결과도 모두 보고한다.

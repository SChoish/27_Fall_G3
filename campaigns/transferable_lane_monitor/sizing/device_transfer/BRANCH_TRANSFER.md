# GF180 분기 회로에서의 고정 정책 비교

2026-11-28. [6단·2단 결합 회로](UNSEEN_ELITE_METRIC.md)에서 고른 elite + adaptive metric 하강 방향을 그대로 사용한다. 1차 비교는 이 구성과 익명 폭 MLP + BO의 5% 정밀 EDP 최초 도달 시간이다. 별도 10% 탐색과 소스가 필요 없는 타깃 전용 BO도 기록한다. 이번 평가에 앞서 조건과 방법을 정하고 다른 하이퍼파라미터를 탐색하지 않는다.

평가 대상은 이미 다른 알고리즘의 벤치마크에 사용한 GF180 5인버터·3출력 분기 회로다. 출력 부하 배율은 0.85, 1.15, 1.40이고 상호 결합은 2.3 fF다. 선택에 사용한 GF180 회로와 배선, 폭 개수(16→10), 부하가 함께 바뀐다. 두 학습 방법은 동일한 SKY130 4회로 × 25설계 × 2코너(200 transient)에서 학습한다. 소스에는 다른 분기 회로가 포함된다. 타깃 소자 역할 표시는 제공하지 않는다.

대응 seed 81–83, 같은 네 랜덤 웜업 및 최초 도달까지 최대 100 SPICE eval을 적용한다. 셀 기준과 지연·slew·전원 민감도·레일 제약, 개발·확인·정밀 검증 규칙은 이전 비교와 동일하다. 예산 미달은 제한평균에 100으로 포함한다. 새 회로에서 5% 성공 수가 유지되거나 늘면서 제한평균이 더 낮으면 이 회로에서 절감이 재현된 것으로 본다. 두 방법이 다 미달이면 상대 성능 판단을 유보한다. 10%도 별도 기록하며, 개발 코너의 통과를 최종 성공과 구분한다.

## 결과

각 셀의 도달 횟수는 seed 81·82·83 순이다. 100번째에 실제 통과한 경우 100으로, 미달은 ‘미달’로 표시한다.

| 방법 | 5% 최초 횟수 | 5% 성공 · 제한평균 | 10% 최초 횟수 | 10% 성공 · 제한평균 |
|---|---|---|---|---|
| 타깃 전용 BO | 56 / 미달 / 82 | 2/3 · 79.33 | 미달 / 미달 / 미달 | 0/3 · 100.00 |
| MLP + BO | 30 / 52 / 50 | 3/3 · 44.00 | 미달 / 미달 / 94 | 1/3 · 98.00 |
| MLP + BO + elite + adaptive metric 경사 | 미달 / 38 / 54 | 2/3 · 64.00 | 미달 / 56 / 미달 | 1/3 · 85.33 |

각 목표의 세 실행에서 **개발 코너 통과 후보 / 확인 코너도 통과한 후보 / 정밀 재검증한 후보 / 최종 성공 실행**을 집계했다. 동일 설계의 반복 방문도 각 궤적에서 비용을 지불한 대로 포함한다.

| 방법 | 5% | 10% |
|---|---|---|
| 타깃 전용 BO | 2 / 2 / 2 / 2 | 1 / 0 / 0 / 0 |
| MLP + BO | 4 / 3 / 3 / 3 | 8 / 1 / 1 / 1 |
| MLP + BO + elite + adaptive metric 경사 | 15 / 2 / 2 / 2 | 11 / 1 / 1 / 1 |

18개 궤적을 원시 코너값에서 독립적으로 재생해 최초 도달, 예산, 동일한 네 랜덤 웜업과 매 후보를 대조했다. 타깃 독립 실행 환산 1,412회, 폭·코너·정밀도로 구분한 고유 타깃 측정 812개다. 비용은 기준과 정밀 검증을 포함한다. 재생은 `python unseen_elite_metric.py --branch --replay`로 실행한다. [원시 측정과 궤적](branch_transfer_measurements.zip) · [비교 코드](unseen_elite_metric.py)

**판단.** 결합 회로에서 관측한 5% 절감 효과는 분기 회로에서 재현되지 않았다. 기본 MLP 대비 elite + metric의 5% 제한평균은 20회 증가했고 성공 수는 한 번 줄었다. 개발 조건을 통과한 방문 15건 중 14건이 확인까지 진행됐다. 12건은 5% EDP를 만족하면서 오직 slew 제약에서 탈락했다(seed 81에서 10건, 82에서 2건). 한 건은 남은 예산으로 확인할 수 없었다. 이 관측은 현재 실패한 조건을 식별하며 구조적 원인이나 다음 규칙의 효과까지 검증한 것은 아니다. 10%에서는 양쪽 모두 1/3이어서 성공률 개선은 없었다. 기본 MLP + BO를 기준으로 유지하고, elite + metric은 특정 구조에서의 유망한 변형으로 보존한다.

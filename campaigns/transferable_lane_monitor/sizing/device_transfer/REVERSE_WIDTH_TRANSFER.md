# GF180 소스 → 새 SKY130 버퍼

2026-11-28. 이전 [SKY130 소스 비교](CORNER_TRANSFER.md)에서 선택한 5% 목표용 elite 폭 매핑을 고정한다. 네 GF180 소스 회로 × nominal 포함 25설계 × 개발 코너 2개, 총 200 transient를 재사용한다. 세 전이군이 쓰는 소스·MLP·타깃 잔차 GP는 같다. 타깃 전용 BO는 소스 비용 0이다. 소스 쪽 MOS 극성과 nominal 폭 순위는 GF180 소자의 넷리스트에서 추출한다.

- **서로 다른 새 타깃.** 단일 입력의 6인버터·2출력 분기와 두 입력의 9인버터·3출력 분기를 SKY130에서 평가한다. 독립 폭은 각각 12개와 18개다. 출력 부하 배율과 결합은 각각 (0.86, 1.42)·2.35 fF와 (1.25, 0.82, 1.50)·2.95 fF다.
- **대응 실험.** seed 111–113, 네 랜덤 웜업, 5%와 10% 목표의 독립 궤적. 1회는 한 코너 SPICE transient이고 기준·개발·확인·0.25 ps 정밀 검증을 100회 안에 계상한다. 확인 코너 관측은 선택기에 전달하지 않는다.
- **비교군.** 타깃 전용 BO, 익명 MLP + BO, 같은 MLP + GF180 elite 폭 매핑, 같은 MLP + 무작위 GF180 설계 폭 매핑. 소스당 우수 설계 세 개, 극성별 폭 순위의 가우시안 매핑 폭 0.2, 국소 256개 및 전역 256개, 무작위 donor 추출 규칙을 이전 설정과 동일하게 사용한다.
- **판정.** 1차 5%에서 성공 수를 유지하거나 높이면서 제한평균이 줄어드는지, 두 타깃에서 결과가 일치하는지 확인한다. 무작위 매핑과의 차이는 고정한 donor 집합 하나에 한정한다. 10%는 별도 보고한다. 두 구조 비교만으로 PDK와 배선 변화의 개별 인과효과를 분리할 수 없다.

### 동일 타깃에서 소스 PDK만 바꾼 대조

역방향 실행 중 두 새 타깃의 결과표를 보기 전에 대조군을 추가했다. 이전 4회로의 동일한 100개 폭에 대한 SKY130 소스 200회로 기본 MLP와 elite 매핑을 각각 재학습하고 타깃 회로·seed·예산·목표·후보 규칙을 고정한다. GF180 소스와 폭 목록이 완전히 일치하는지 확인한다. SKY130 소스의 타깃 전용 BO는 같은 궤적이므로 중복 실행하지 않는다. 이 비교에서 입력 PDK의 차이는 학습 레이블과 elite로 선택된 설계 및 학습된 예측 평균에 함께 반영된다.

## 판단

5%에서 GF180 elite 매핑은 기본 MLP와 같은 3/6을 달성하고 제한평균을 88.00회에서 83.67회로 줄였다. 회로별로는 2출력에서 성공 수가 3/3→1/3, 3출력에서 0/3→2/3으로 바뀌었다. 무작위 소스 매핑은 4/6·93.00회였다. 따라서 역방향 전이에서 일반적인 성공률 우위는 확인되지 않았다. 같은 타깃에 SKY130 소스를 쓴 elite 대조도 2/6이어서 두 회로의 어려움을 소스 PDK 차이 하나로 설명하기 어렵다.

2출력 5%에서 elite가 확인한 19건 중 1건만 확인 통과했다. 14건은 slew만, 2건은 EDP와 slew, 2건은 EDP만 미달했다. 같은 조건의 기본 MLP는 12건 확인 중 4건이 확인을 통과했고 정밀 재검증에서 최종 3건이 남았다. 타깃에 접수된 후보 집합 자체가 달라 해당 수치를 동일 후보의 실패율 차이로 해석하지 않는다. 역방향 10% 탐색에서 개발 EDP를 달성한 후보 방문 4건 모두 개발 slew를 초과해 확인 단계에 진입하지 못했다. 예산 내에서 관찰한 사실이며 물리적 달성 불가능성을 증명하지 않는다.

기본 MLP + BO를 비교 기준으로 유지하고 소스 elite 매핑은 초기에 유용할 수 있는 후보 생성기로 유지한다. 이후에는 같은 시작점에서 소스 순위 상위 설계의 폭 변화를 nominal과 보간해 보폭과 slew 위험의 관계를 분리해 보는 것이 다음 검증 후보다. 확인 결과는 정책 입력에서 계속 제외한다.

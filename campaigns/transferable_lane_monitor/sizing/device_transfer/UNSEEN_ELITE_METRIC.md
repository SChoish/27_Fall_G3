# 미관측 공정에서 elite와 adaptive metric이 줄이는 타깃 SPICE 비용

2026-11-28. 고정한 비교는 부하 변경 6단·2단 결합 버퍼 한 개의 SKY130 → GF180 방향, seed 81–83, 독립적인 5% 및 10% EDP 목표다. 이전 실험에서 이미 사용한 GF180 타깃을 같은 설정으로 재사용한다. 학습에 넣는 4개 소스 회로 × 25개 폭 × 2코너는 전부 SKY130이다. GF180 사전학습·확인 코너 관측을 제안기에 주지 않는다. 새 회로의 이미 지불한 개발 관측은 모든 방법에서 허용한다. 타깃 기준부터 독립 정밀 확인까지 100회, 1회는 단일 동작점의 SPICE transient다. 미달은 제한평균에 100으로 들어간다.

1. 타깃 전용 BO, SKY130 익명 폭 MLP + BO, SKY130 실제 배선 GAT + BO를 비교한다. GAT에서 학습 시 없던 PDK의 ID를 0으로 마스킹하고 타깃 넷리스트의 물리량과 연결은 제공한다. 네트워크를 고정하고 개발 관측에 GP 잔차를 맞춘다.
2. 같은 익명 MLP + BO를 기준으로 elite만, metric만, 둘 다를 추가한다. 256개 국소 후보와 256개 전역 후보, GP, 획득함수, 명목 기준 및 네 랜덤 웜업이 같다. Elite는 지금까지 실제 측정한 개발 목적값(로그 EDP + 양의 로그 제약 위반 합의 4배)이 가장 낮은 세 설계에 국소 후보를 나눠 배치한다. 기본은 최상위 한 설계다.
3. Adaptive metric은 attention 없이 매 제안 때 각 중심에서 현재 MLP+GP 예측의 부드러운 제약 비용을 범위 정규화 로그 폭으로 미분한다. g를 그 기울기라 하면 기존 ALARM식 G = ggᵀ + diag(0.7g² + λ), λ = 0.015 mean(g²) + 0.0001을 쓴다. 국소 후보 변위에 G의 역제곱근을 곱하고 길이를 복원하며 경계에서 반사한다. 유한차분은 대리모델만 호출한다. 기존의 단일 하강 방향에 대한 역행렬 갱신을 이번에는 BO 후보의 분포에 적용한 변형이다. 독립적인 metric 파라미터 학습이나 추가 SPICE는 없다.
4. 주 지표는 정밀 검증된 5% 성공 수와 제한평균, 10%는 별도 보조 지표다. 동일 seed별 원시 도달 시점을 보존한다. 효과는 elite 대 단일 중심, metric 대 기본 좌표, 양쪽을 사용했을 때의 조건부 차이로 읽는다. 한 구조·한 타깃 공정의 세 반복이므로 공정 전반의 우위나 통계적 동등성을 추론하지 않는다.

### 탐색 방향 보조 비교

주 비교 일부를 확인한 뒤 추가했다. 위 metric이 후보의 분산 방향을 바꾼다는 점을 고려해 ALARM의 하강 방향 사용법도 별도로 점검한다. 같은 세 elite에서 시작하는 일반 경사 −g와 전처리 경사 −G⁻¹g를 비교한다. 최대 성분으로 하강 방향을 정규화하고 같은 보폭과 perturbation을 적용해 256개 국소 후보를 만든다. 나머지 256개 전역 후보와 BO 점수는 원래대로 유지한다. 3 seed × 2 목표 × 2 방법이며 주 비교의 2×2 분석에 합치지 않는다. 앞선 역할 기반 구현의 Armijo 검사와 critic 업데이트까지 재현하는 실험은 아니다.

## 최초 도달 결과

각 칸의 세 수는 seed 81/82/83 순서의 정밀 검증까지 지불한 타깃 transient 수다. 실패를 100회로 넣은 제한평균과 성공 수도 함께 표시했다.

| 방법 | 5% 호출 수 | 5% 성공 · 평균 | 10% 호출 수 | 10% 성공 · 평균 |
|---|---|---|---|---|
| 타깃 전용 BO | 미달 / 미달 / 미달 | 0/3 · 100.00 | 미달 / 미달 / 미달 | 0/3 · 100.00 |
| 익명 폭 MLP + BO | 38 / 50 / 52 | 3/3 · 46.67 | 46 / 92 / 76 | 3/3 · 71.33 |
| 실제 배선 GAT + BO | 96 / 56 / 48 | 3/3 · 66.67 | 92 / 70 / 미달 | 2/3 · 87.33 |
| MLP + elite | 32 / 42 / 88 | 3/3 · 54.00 | 78 / 74 / 미달 | 2/3 · 84.00 |
| MLP + adaptive metric | 미달 / 미달 / 미달 | 0/3 · 100.00 | 미달 / 미달 / 미달 | 0/3 · 100.00 |
| MLP + elite + adaptive metric | 미달 / 72 / 미달 | 1/3 · 90.67 | 미달 / 미달 / 미달 | 0/3 · 100.00 |

### 같은 MLP 안에서의 대응 효과

변경 후 제한평균에서 변경 전 제한평균을 뺀 값이며 음수이면 더 빨랐다.

| 변경 전 → 변경 후 | 5% 호출 수 차이 | 10% 호출 수 차이 |
|---|---:|---:|
| 익명 폭 MLP + BO → MLP + elite | +7.33 | +12.67 |
| MLP + adaptive metric → MLP + elite + adaptive metric | -9.33 | +0.00 |
| 익명 폭 MLP + BO → MLP + adaptive metric | +53.33 | +28.67 |
| MLP + elite → MLP + elite + adaptive metric | +36.67 | +16.00 |
| 익명 폭 MLP + BO → MLP + elite + adaptive metric | +44.00 | +28.67 |

36개 궤적의 모든 후보, 원시 코너 측정값, 웜업, 최초 도달 비용을 재생했다. 6개 타깃 전용 BO 기록을 재사용했다. 방법별 독립 실행으로 계상한 타깃 비용은 3,002회이고, 같은 폭·코너·정밀도를 합친 고유 타깃 측정은 1,488개다. 학습군의 원천 데이터는 동일한 SKY130 200회다. 반복 간 같은 결과가 재현되는지는 세 개의 대응 seed에서 기술적으로 비교했다.

[원시 데이터와 궤적](unseen_elite_metric_measurements.zip) · [실행 및 검증 코드](unseen_elite_metric.py). 기존 ngspice 경로 인수로 `python unseen_elite_metric.py search`를 실행한다. 저장 파일만으로는 `python unseen_elite_metric.py --replay`를 사용한다.

방향 보조군의 5% 중간값을 본 뒤, 시작점 수의 효과를 하강 방향과 분리하기 위해 같은 일반 경사와 전처리 경사를 단일 최상점에서도 실행했다. 목표, 세 seed, 방향 생성 규칙, 국소 후보 수를 그대로 사용했다. 이 두 행도 탐색적 결과로 보고한다.

## 명시적으로 하강 방향을 제안한 보조 결과

각 시작점에 잡음을 넣지 않은 후보 한 개를 포함하므로 단일과 elite의 무잡음 후보 수는 각각 1개와 3개다. 같은 시작점 수에서 일반 경사와 metric 경사의 무작위 perturbation, 보폭, 후보 수는 동일하다. 두 탐색 방향은 모두 MLP + 타깃 잔차 GP의 같은 비용을 미분한다. 표는 이전 주 비교와 동일한 GF180 회로, 3 seed, 100회 검증 예산을 사용한다. 

| 방법 | 5% 호출 수 | 5% 성공 · 평균 | 10% 호출 수 | 10% 성공 · 평균 |
|---|---|---|---|---|
| 단일 시작점 + 일반 경사 | 28 / 미달 / 28 | 2/3 · 52.00 | 88 / 100 / 62 | 3/3 · 83.33 |
| 단일 시작점 + adaptive metric 경사 | 34 / 80 / 66 | 3/3 · 60.00 | 78 / 미달 / 90 | 2/3 · 89.33 |
| Elite + 일반 경사 | 30 / 54 / 미달 | 2/3 · 61.33 | 36 / 52 / 미달 | 2/3 · 62.67 |
| Elite + adaptive metric 경사 | 36 / 30 / 24 | 3/3 · 30.00 | 미달 / 미달 / 78 | 1/3 · 92.67 |

두 방향 보조군은 각각 12개 궤적을 다시 검산했다. 아래 ZIP과 대응 코드로 동일한 후보 및 비용을 재생한다.

[Elite 시작점의 원시 궤적](unseen_directional_measurements.zip) · [단일 시작점의 원시 궤적](unseen_single_directional_measurements.zip). 검증 명령은 `python unseen_elite_metric.py --directional --replay`와 `python unseen_elite_metric.py --single-directional --replay`다.

### 판단

같은 GF180 회로의 세 seed에서 elite + adaptive metric 경사 방식은 5% 목표를 기본 MLP보다 각각 2·20·28회 빨리 달성했다. 같은 elite에서 일반 경사를 사용할 때는 2/3·61.33회였고, 단일 시작점에서 adaptive metric 경사를 사용할 때는 3/3·60회였다. 10%에서 elite + metric 경사는 한 번만 통과했다. 따라서 5%에는 두 요소를 조합한 방향 제안을 별도 회로에서 재검증할 후보로 유지한다. 10%에는 기본 익명 MLP를 기준으로 유지한다. 여러 변형을 본 단일 GF180 회로의 결과이며, 재검증 전에 전체 회로에 쓸 기본 정책을 교체할 근거는 제한적이다.

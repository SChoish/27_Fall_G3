# Attention-free metric, coordinates and warm-up

Tune on four previously measured domains (fork, mixed_gf, load_sky, seven_sky), seeds 21–23. The independent test uses seeds 31–35 on two matched SKY130/GF180 pairs: a new load/coupling combination and a new three-output eight-inverter topology. All inputs, network connections and bounds are in warm_space.py. The physical variables are separate NMOS/PMOS width ratios; length is fixed by PDK and multiplicity is implicit one. Compare log width relative to nominal against that log coordinate divided by log(upper/lower), using the same physical candidate set, role move, critic inputs and random streams. The range normalization is a search metric change, not a new simulator parameterization.

The primary score is circuit-balanced capped mean calls to a 5% verified EDP improvement, then 10% capped mean as tie-breaker. Count four reference transients, two per development query and two confirmation calls for a development-feasible 5% candidate when affordable. A warm-up sample can hit the target; no warm-up or confirmation call is free. Bound each trajectory by 40. Confirmation results never train or rank designs. Development premeasures a finite candidate bank to allow paired factorial screening; hidden unqueried outcomes are unavailable to policies. Report benchmark construction costs separately. Test the best development configurations and matched controls on the untouched test pairs, including the existing continuous scalar optimizer. Evaluate all recorded first hits again at 0.25 ps. Source MLP data cost is the existing 324 SKY130 transients.

Warm-up arms use 0, 1, 2 or 4 extra samples from a local or full log-uniform physical-width bank. Compare role first vs random first using the same warm-up samples. Test sizes 2, 4, 8 and reuse probabilities 0.25, 0.50, 1 for stored MLPs; contrast random and scored selection at matched capacity/gate. A development observation scores models before it is used for training. Compare a target residual calibrated from previously observed width changes against the uncorrected surrogate. Freeze the chosen full configuration plus warm-only and buffer-only configurations before acquiring test measurements. Report training configuration selection costs and keep the held-out estimates separate.

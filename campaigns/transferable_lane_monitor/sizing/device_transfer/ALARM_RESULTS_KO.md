# ALARM 구성요소의 목표 도달 비용

5% 목표에서 다섯 조건의 제한 평균은 elite + ALARM 균일 대각 가중치가 19.20회로 가장 낮았고, 새 세 조건에서는 elite + 일반 경사가 21.33회로 가장 낮았습니다. 10% 목표는 다중 지표 metric이 34.40회로 가장 낮았으나 성공은 4/15회였고 모두 GF180에서 나왔습니다. 두 성과는 서로 다른 목표에 대한 것입니다.

같은 일반 경사에 elite 시작점을 추가하면 새 조건에서 5% 도달 비용이 27.33회에서 21.33회로 줄었습니다. 학습 대각과 과거 SPICE surrogate의 점수 재사용은 5% 전체 평균을 개선하지 못했습니다. 기준 역할 규칙과 ALARM 균일 대각 방법의 5% 전체 타깃 비용차는 3.60회입니다. 같은 회로 분포와 평균 절감량을 가정하면 324회 소스 비용을 새로 지불하는 경우 약 90건의 타깃이 필요합니다. 이미 소스 데이터를 보유했다면 신규 타깃의 추가 비용을 따로 볼 수 있습니다.

표는 성공 수/시행 수와 40회 제한 평균 SPICE 호출 수입니다. 미도달도 40회로 포함했으며 실제 40회째 성공은 성공 수에 포함합니다. 회로에 동일 가중치를 주었습니다. 목표는 모든 출력·동작점에서 EDP를 기준 대비 각각 5%, 10% 줄이면서 지연·slew·레일·전원 민감도 제약을 만족하는 것입니다. 최초 4회는 기준, 개발 2회와 확인 2회를 포함해 최솟값은 8회입니다.

## 0.25 ps 재검산

각 회로와 목표에서 최초 도달이 가장 빨랐던 설계를 재검산했습니다. 동률이면 방법명·seed의 사전순으로 하나를 선택했습니다. 참조 탐색은 네 동작점을 모두 사용해 4개 역할·극성 변수에 대해 유한차분을 수행한 별도 실행입니다. 해당 탐색의 실패만으로 10% 달성 불가능을 판단할 수 없습니다.

## 모든 최초 도달 설계 재검산

알고리즘·회로·seed·목표별 최초 도달 기록 128개에 대해, 중복 제거한 후보 79개를 모두 0.25 ps로 재실행했습니다. 128개 기록이 같은 목표를 다시 통과했습니다. 비용은 기준 재계산을 포함해 336회이며 위 표의 재검산 비용과 별도입니다.

## 비대칭 부하의 달성 가능성

load_sky에서 같은 역할의 두 lane을 같은 폭으로 묶은 참조 탐색이 목표를 놓친 뒤, 독립적인 8개 폭을 조절하는 사후 참조 탐색을 수행했습니다. 네 동작점 모두 사용한 비용은 168회이고, 가장 낮은 실측 EDP/기준은 0.952776입니다. 추가 8회로 검산한 값은 0.953135입니다. 이 확인은 타깃 알고리즘의 도달 기록에 포함하지 않았습니다.

5% 경계 부근을 별도로 재탐색했습니다. 소자별 제약 선형화와 더 작은 차분폭을 사용한 추가 비용 120회, 최종 시간 간격 재검산 8회에서 재검산 EDP/기준은 0.949585였습니다. 기존 두 참조 탐색 기록도 모두 남겼습니다.

## 비용과 재현

- 원시 측정에서 175개 시행의 모든 제약 판정과 최초 도달 호출 수를 다시 계산했습니다. 방법별 독립 실행 환산 비용은 6,684회입니다. 타깃 원시 측정 5,100개 중 기존 실측 캐시에서 가져온 것은 40개이며, 시뮬레이터 오류는 0개였습니다.
- 역할 규칙과 BO는 소스 비용 0회, 학습 방법은 같은 SKY130 소스 324회입니다. 참조 탐색 384회, 0.25 ps 재검산 64회는 별도입니다.
- 저장한 시뮬레이션 값을 메모리에서 읽어 175개 알고리즘 궤적을 완전히 재생했습니다. seed당 소스 SPICE surrogate 학습은 0.050 CPU초, 좌표 가중치 학습은 0.138 CPU초였습니다. 전체 재생과 방법별 타깃 SPICE surrogate 학습·후보 제안 시간은 [시간 로그](runs/alarm/timing.json)에 있습니다. SPICE 실행 시간은 이 CPU 시간에 포함하지 않았습니다.
- 학습 대각 + 무작위 buffer가 snapshot을 초기값으로 선택해 다시 학습한 횟수는 143회입니다. 직전 갱신보다 더 오래된 모델을 선택한 경우는 115회였습니다.
- 학습 대각 + 점수 buffer가 snapshot을 초기값으로 선택해 다시 학습한 횟수는 158회입니다. 직전 갱신보다 더 오래된 모델을 선택한 경우는 94회였습니다.
- SPICE surrogate의 해석적 Jacobian을 중앙 유한차분과 대조했고, 네 방향의 하강성, 소자 순열 불변성, encoder 고정 및 snapshot 복사 독립성을 확인했습니다.
- ALARM 원문을 바탕으로 만든 변형입니다. 역할 특성을 소자 전체에 집계한 MLP, 소스에서 학습한 좌표별 softmax 대각 가중치, 12개 방향 × 5개 스텝 후보를 사용합니다. 허용 범위에서 Armijo를 만족한 후보에 우선순위를 주고, 전부 탈락하면 예측 비용으로 결정합니다. 후보 슬롯 수는 같아도 초기 elite 개수에 따라 중복 좌표 수는 다를 수 있습니다. buffer 점수는 과거 벡터 예측오차·실측 비용 변화·현재 중심과의 거리를 사용합니다. 이식한 buffer는 한 타깃 안에서만 모델을 다시 고릅니다.
- 해당 비교는 셀 수준 SPICE입니다. 검증 대상은 부하·결합·회로 배선·PDK 변화이며 전체 패키지 signoff는 포함하지 않습니다.

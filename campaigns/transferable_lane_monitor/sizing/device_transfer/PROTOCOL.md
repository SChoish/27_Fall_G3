# Transfer of transistor-level sizing moves

Use separate relative NMOS and PMOS widths for every inverter, bounds [0.58,1.30] (source-facing inputs capped at 1.0). Each circuit gets its own nominal widths and its own reference. Source SKY130 circuits are a two-stage chain, a four-stage chain, and a four-stage fanout with an extra terminal load branch. Target tests are a different SKY130 shared-prefix fork, two capacitively coupled SKY130 lanes, the same coupled lanes in GF180, and coupled GF180 lanes of unequal depths and load. Count an actual transient at one operating point as one evaluation; all outputs and both edge polarities are measured together. Test anti-phase aggressors in both development corners, then same-direction switching in the two confirmation corners. For the fork the two outputs follow the same root. Monitor worst EDP across ports/corners, delay, 20–80% slew, rail settling, and supply sensitivity. Normalize each port against its own reference under identical stimuli. Use aggregate supply energy for the entire network in each port EDP. Primary threshold 5%, additional 10%. Use the existing four corner roles and 40-call cap including four reference calls. Confirm whenever development passes 5% and all constraints; do not pass confirmation results to the proposer. These tests qualify the simulated coupled buffer cells, not a complete package.

Train local sensitivity predictors only on source development measurements. Use the same one-device perturbations for all shared heads. Compare uniform and cold target-probability BO, transfers with no message passing and typed graph aggregation, adaptive versus frozen heads. Include a topology-blind polarity baseline. No direct source action replay is assumed across dimensions. Use paired seeds 21,22,23. Report first-proposal success and restricted mean evaluations, retain failures. Cache identical raw SPICE evaluations across runs, count their stand-alone information cost equally to each run, and report actual physical executions separately. Do not infer an architecture winner from pooled seeds as independent target circuits.

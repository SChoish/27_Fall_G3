# G3 simulation-to-target protocol

The primary cost is one executed SPICE evaluation (a transient analysis for one circuit, design and stimulus/corner). A single waveform yielding several metrics costs one. Separate transients, failed launches that enter simulation, and independent verification transients each count. Record cache hits and surrogate predictions separately at zero incremental SPICE cost. A suite evaluating four cases typically costs four. A simultaneous batch incurs all actually executed transients, including work in flight when a hit is discovered.

Specify a physical FoM threshold, direction, hard constraints, and verification suite before ranking algorithms. Share the design domain, initialization protocol, fidelity, hardware/parallelism where time is compared, and evaluation cases. When common initial observations are precomputed, disclose their physical generation cost and charge the same stand-alone information cost to all methods. For transfer, report the source-generation cost, additional target-circuit simulations and cumulative cost across a stated number of target circuits.

Report the fraction of independent runs with a verified feasible target hit as a function of cumulative SPICE calls. Keep unsuccessful runs as right-censored at a common cap. Report success at cap and restricted mean calls to that cap (and median if estimable). Plot feasible best-so-far against calls as a secondary result. Lock candidate, rules and verification triggers, never use a final test bank for acquisition. Development-only historical hits must be labelled separately.

## Earlier lane monitor pilot

The reference path in REVISION provides a frozen delay lookup and precomputed channel transfer functions. One local measurement every four blocks in 128 blocks is a runtime sensing budget. This experiment can study monitoring but does not charge SPICE during candidate search. Its lane-probe counts cannot establish simulation efficiency. Source data retain their original attribution. No SPICE was launched to generate the local scheduler pilot.

## Physical sizing pilot (fixed before optimization)
The default threshold is 10% lower worst-case, corner-normalized cell EDP. Also report 5% and 20% thresholds. For each transient, integrate energy drawn from the buffer VDD over one full, settled input cycle and use the slower of the two 50%-crossing propagation delays. Normalize EDP to the nominal-width buffer at the very same operating point. Require each edge delay and output 20–80% slew <= 1.10 times the reference at that point, stable logic levels <= 0.1 VDD and >= 0.9 VDD, and worst absolute same-edge low-voltage delay shift <= 1.05 times the reference worst shift at that load and temperature. These thresholds are research choices, not standards. Report E, delay, slew and supply sensitivity independently. The first-stage input widths cannot exceed the reference; the ideal stimulus driver energy is outside the cell energy boundary.

Each design is first simulated at 8 fF, 27°C, 1.80 and 1.66 V. When it passes the loose 5% target and constraints, the same design is checked at 12 fF, 70°C, 1.80 and 1.62 V. The acquisition rule never sees confirmation waveforms, aggregate values or pass/fail. Run up to 40 physical calls per method and seed, never launch a partial corner pair. Count all four reference calls. A later, independently designed link-level test is needed to claim package margin or BER improvement.

Use the original two-stage widths 1,2 µm (N) and a separate four-stage chain with N widths 1,2,2,4 µm. P widths are twice N widths. The search space is shared across stage counts: two log-interpolated width multipliers at the input and output, respectively in [0.5,1] and [0.5,1.6]. Compare uniform search, a constrained kernel surrogate and a target-only structured width sweep; compare source replay and a source-prior surrogate on the four-stage circuit. Ground amortized costs in measured source calls. Use six paired seeds 11–16, disjoint validation conditions and one reference plus one shared random design per seed. This is a pilot across two topologies in one TT PDK. The simulation unit and confirmation gate take precedence over the earlier monitor pilot.

## Secondary link audit and target-directed BO comparator
Before inspecting method outcomes, preselect the seed-11 cold kernel trace on the two-stage circuit and seed-11 residual transfer trace on the four-stage circuit for a board-level model check. Choose the first ten-percent cell hit, if present. Otherwise use the best development EDP among feasible visited designs (reference allowed). Lock each design before generating package trajectories. At 27°C, generate its 5-load by 6-voltage delay grid and that of its topology's nominal-width reference with full SPICE. Compare under the unchanged 32 Gb/s layout-2 package, fixed original information-greedy filter calibrated to the corresponding reference, four drift conditions, 256 paired trajectories per condition and 32 local reads. The design passes the link noninferiority screen if, in every condition, the upper simultaneous 95% paired-bootstrap bound for the absolute increase in failing-block fraction is <= 0.01 (one percentage point). Energy and EDP are at cell scope; link failures use the specified deterministic margin proxy with stochastic packets and drift. This separate screen tests two representatives only; count its grid simulations separately and do not relabel historical first-hit counts as verified link-level first hits.

Add a fixed-target GP baseline that chooses the probability of crossing EDP<=0.90 and all development constraints, using marginal Gaussian predictions. Include a transfer variant with a source prior and a GP over target residuals. Its acquisition is fixed on the primary 10% threshold; 5% and 20% are secondary. Do not adapt settings to campaign results.
